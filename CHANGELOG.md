# Changelog

## 0.1.0-alpha.1

First experimental registry: native Goose resolver, static per-package TOML
index, conditional HTTP requests, verified content cache, offline lock records,
concurrent fetch serialization, and bounded archive extraction. Includes offline
Python publication tools, a static catalog, and Honk integration with add,
search, info, fetch, update, and frozen builds. One package version per graph;
no feature flags, multi-version imports, authenticated registries or publish API.
